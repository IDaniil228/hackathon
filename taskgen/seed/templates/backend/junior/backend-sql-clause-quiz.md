## Генерация

Опиши кейс в домене: {domain}. Аналитик просит разработчика выгрузить данные из реляционной базы. Опиши таблицы, которые упомянуты в фактах, и что именно нужно в выгрузке, словами аналитика, без кода SQL.

## Вопрос

Какая конструкция SQL нужна, чтобы выполнить ключевое требование выгрузки из кейса?

## Варианты

### filter-rows

Факты:
- table: в таблице orders каждая строка — один заказ, у заказа есть номер клиента и сумма
- need: в выгрузку должны попасть только заказы клиента с номером 42, каждый своей строкой

Ответ:
+ WHERE
- HAVING
- JOIN
- DISTINCT

### filter-groups

Факты:
- table: в таблице orders каждая строка — один заказ, у заказа есть номер клиента и сумма
- group: выгрузка группирует заказы по клиенту и считает число заказов каждого клиента
- need: в выгрузке нужны только клиенты, у которых больше пяти заказов

Ответ:
+ HAVING
- WHERE
- JOIN
- DISTINCT

### combine

Факты:
- table: номер клиента хранится в таблице orders, а имя клиента — только в таблице customers
- need: в каждой строке выгрузки должны быть номер заказа и имя клиента, который его сделал

Ответ:
+ JOIN
- WHERE
- HAVING
- DISTINCT

### unique

Факты:
- table: в таблице customers у каждого клиента есть город, и в одном городе живёт много клиентов
- need: выгрузка — список городов, где есть клиенты, и каждый город в нём ровно один раз

Ответ:
+ DISTINCT
- WHERE
- HAVING
- JOIN

## Нельзя раскрывать

- where
- having
- join
- distinct
- соедин
- уникальн
