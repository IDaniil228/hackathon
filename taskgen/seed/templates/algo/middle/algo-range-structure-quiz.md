## Генерация

Опиши кейс в домене: {domain}. Сервис получает поток операций над данными, описанными в фактах, и должен отвечать на каждый запрос сразу. Расскажи, откуда берутся операции и почему важна скорость ответа.

## Вопрос

Какая структура данных обработает весь поток операций из кейса быстрее всего?

## Варианты

### groups

Факты:
- data: есть миллион объектов, и вначале каждый сам по себе
- merge: операция объединения сливает две группы объектов в одну, и группы никогда не распадаются
- query: запрос спрашивает, состоят ли два объекта сейчас в одной группе

Ответ:
+ Система непересекающихся множеств
- Префиксные суммы
- Дерево отрезков
- Двоичная куча

### static-sums

Факты:
- data: есть массив из десяти миллионов чисел, и после загрузки он не меняется
- query: запрос спрашивает сумму элементов массива с i-го по j-й, и запросов сотни миллионов

Ответ:
+ Префиксные суммы
- Система непересекающихся множеств
- Дерево отрезков
- Двоичная куча

### dynamic-sums

Факты:
- data: есть массив из десяти миллионов чисел
- update: операция изменения записывает новое значение в один элемент массива
- query: запрос спрашивает сумму элементов массива с i-го по j-й
- mix: изменения и запросы идут вперемешку, тех и других сотни миллионов

Ответ:
+ Дерево отрезков
- Система непересекающихся множеств
- Префиксные суммы
- Двоичная куча

## Нельзя раскрывать

- union-find

- префикс
