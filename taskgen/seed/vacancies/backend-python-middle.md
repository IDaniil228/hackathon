# Python-разработчик бэкенда (Middle)

## Команда

Платёжная команда маркетплейса: шесть бэкенд-разработчиков, QA и продакт. Команда отвечает за приём платежей, возвраты и выплаты продавцам. Через сервис проходит около 300 платежей в секунду в пике

## Стек

Python 3.12, Django и Django REST Framework, PostgreSQL, Redis, Celery, Docker, Kubernetes, Grafana и Sentry

## Задачи

- Развивать API платежей и возвратов: новые способы оплаты, частичные возвраты, повторные списания
- Делать операции идемпотентными и безопасными при повторных запросах и сбоях сети
- Ускорять медленные эндпоинты: запросы ORM, индексы, кэширование
- Писать тесты и участвовать в ревью кода

## Требования

- Коммерческий опыт на Python и Django от двух лет
- Уверенный SQL: индексы, планы запросов, транзакции
- Понимание HTTP API: коды ответов, валидация, пагинация, ограничение частоты запросов
- Опыт с Docker: сборка образов, локальное окружение на docker compose
- Будет плюсом: опыт с платёжными системами и кэшированием в Redis
