В этом проекте независимые подзадачи делятся между субагентами на opus, одновременно работают не больше трёх. Главный агент следит за ними и проверяет каждый отчёт по diff и тестам

**Why:** владелец задачи явно разрешил это для хакатона, чтобы ускорить работу без потери качества

**How to apply:** при запуске субагента передавать модель opus явно; держать не больше трёх активных; результат агента не принимать на слово, а сверять с diff и прогоном тестов. Связано с [[taskgen-decisions]]
