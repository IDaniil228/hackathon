Сервис `taskgen/` (ветка `task-generation`) генерирует и оценивает задания для теста на грейд. Когда появится `docs/taskgen/`, эта запись заменяется ссылкой на него

- Отдельный FastAPI-сервис, сервисные ключи с ролями `admin` и `client`
- Шаблоны заданий — md-текст в БД (Postgres + pgvector), загрузка папкой через CLI и через API upsert
- Отбор шаблонов: softmax по расстоянию `α·|Δгрейд| + β·(1 − sim)` с температурой `t` из конфига теста; без эмбеддингов — случайный отбор
- Генерация "шаблон + проверка": эталон и тесты в шаблоне, LLM меняет легенду и параметры, экземпляр выдаётся после прогона эталона в Piston
- Балл — взвешенная сумма из конфига с жёстким гейтом по тестам; грейд оценивается по уровням
- Детект ИИ — выключенный по умолчанию плагин, на балл не влияет
- Machine summary — одна запись, перезаписывается только сервисом

**Why:** ТЗ оценивает устойчивость к утечке и сопоставимость сложности (критерий 2, 25 %)

**How to apply:** новые решения сверять с этим списком, расхождение обсуждать с владельцем задачи. Связано с [[opus-agents-parallel]]
