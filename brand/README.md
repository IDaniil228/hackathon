# Фирменный стиль ФСП

[![assets](https://img.shields.io/badge/docs-assets-555?style=flat)](ASSETS.md)

Визуальная основа фронтенда платформы подбора ИТ-кандидатов по [брендбуку Федерации спортивного программирования](https://fsp-russia.ru/press/brandbook/). Набор не зависит от фреймворка: CSS-переменные, базовые стили компонентов и пресет Tailwind, собранные из одного файла токенов

Откройте [preview.html](preview.html) в браузере, чтобы увидеть палитру, шрифт, логотип с охранным полем, все компоненты и два макета экранов: карточку кандидата в выдаче работодателя и входящее приглашение у кандидата. Сервер не нужен

## Состав

| Файл | Назначение |
| --- | --- |
| [tokens.json](tokens.json) | Единственный источник правды: цвета, шрифт, шкала текста, отступы, радиусы, тени, брейкпоинты, длительности. У каждого значения указан источник или правило вывода |
| [build.py](build.py) | Генерирует `dist/tokens.css` и `dist/tailwind.preset.js` из `tokens.json` |
| [dist/tokens.css](dist/tokens.css) | CSS-переменные `--fsp-*`: светлая тема на `:root`, тёмная по системной настройке или атрибуту `data-theme="dark"` |
| [dist/base.css](dist/base.css) | Типографика, ссылки, фокус, формы, кнопки, карточки, статусы, таблицы, навигация кабинета, уведомления. Пишется вручную и использует только переменные |
| [dist/tailwind.preset.js](dist/tailwind.preset.js) | Пресет Tailwind CSS v3, все значения ссылаются на CSS-переменные |
| [contrast-pairs.json](contrast-pairs.json) | Пары "текст/фон", которые встречаются в `base.css` |
| [check_contrast.py](check_contrast.py) | Проверка контраста WCAG 2.1 для этих пар в обеих темах |
| [fetch_logos.py](fetch_logos.py) | Скачивает логотипы ФСП в `assets/logo/` |
| [test_build.py](test_build.py) | Тесты сборки, происхождения цветов и контраста |

## Что взято из брендбука

Брендбук ФСП опубликован как веб-страница и архив `брендбук.rar` с картинками, логотипами и шрифтом. Отдельного PDF с правилами нет, поэтому всё, что брендбук не называет прямо, выведено и помечено в `tokens.json` полем `$derived`

- Фирменные цвета `blue`, `red` и `light` указаны в разделе "Стандартный вариант использования логотипа", а `gray` и `dark` в разделе "Логотип / вариации" для версии на светлом фоне. Значения лежат в группе `palette` файла `tokens.json` с полем `$source`
- Шрифт JetBrains Mono из раздела "Шрифт" и из архива брендбука
- Версии логотипа для тёмного и светлого фона из разделов "Логотип / вариации" и "Логотип / дополнительные варианты"
- Графический элемент "Линии графики" из раздела "Графика / Основные элементы": тонкая линия с точками на концах. По нему сделаны разделитель `.fsp-rule` и линии на витрине

## Что выведено и по каким правилам

- Семантические цвета (`theme.light` и `theme.dark`) получены смешением фирменных цветов в sRGB. Доля смеси подобрана так, чтобы пара проходила порог контраста, а не на глаз. Литерал цвета разрешён только в `palette`, это проверяет тест
- Чистый красный не годится под мелкий белый текст, поэтому кнопка опасного действия использует красный, слегка затемнённый к фирменному тёмному. Фирменный красный остаётся акцентом для графики
- На тёмном фоне фирменный синий слишком тёмный для текста, поэтому ссылки и включённые переключатели в тёмной теме осветлены к фирменному светлому
- Зелёного и жёлтого в палитре нет, и их не добавляли. Статусы приглашений и откликов различаются оттенками синего, серого и красного, а подпись и точка дублируют цвет. Названия статусов совпадают с `hire.invitation_status` из [docs/Структура БД.md](../docs/Структура%20БД.md)
- Тёмная тема разрешена самим брендбуком: у каждой версии логотипа есть вариант для тёмного фона, а страница брендбука сама тёмная
- Белый не входит в фирменную палитру и используется как нейтральная поверхность карточек
- Радиусы и брейкпоинты взяты из CSS официального сайта fsp-russia.ru. Шкала текста, отступы, высоты элементов и длительности анимаций подобраны под моноширинный шрифт и в брендбуке не заданы
- Основной текст набран тем же JetBrains Mono, что и заголовки, потому что брендбук называет один шрифт. Если команда выберет отдельный шрифт для длинного текста, достаточно поменять токен `font.family.text`

## Подключение

### Чистый CSS

```html
<link rel="stylesheet" href="brand/dist/tokens.css">
<link rel="stylesheet" href="brand/dist/base.css">

<button class="fsp-btn fsp-btn--primary">Пригласить</button>
<span class="fsp-badge fsp-badge--sent">Отправлено</span>
```

`base.css` подключает шрифт относительным путём `fonts/`, поэтому папку `dist` копируйте целиком

### React, Vue и другие фреймворки

Импортируйте оба файла один раз в точке входа приложения, а в компонентах используйте классы `fsp-*` или переменные `var(--fsp-*)` в своих стилях

```js
import "../brand/dist/tokens.css";
import "../brand/dist/base.css";
```

Тему переключает атрибут на корневом элементе: `document.documentElement.dataset.theme = "dark"` или `"light"`. Без атрибута тема следует системной настройке

### Tailwind CSS

Подключите `tokens.css` в глобальных стилях и добавьте пресет в `tailwind.config.js`

```js
module.exports = {
  presets: [require("./brand/dist/tailwind.preset.js")],
  content: ["./src/**/*.{html,js,jsx,ts,tsx,vue}"],
};
```

Цвета доступны как `bg-fsp-primary`, `text-fsp-text-muted`, `border-fsp-border` и поддерживают прозрачность вида `bg-fsp-primary/50`. В Tailwind v4 тот же пресет подключается директивой `@config`

## Пересборка и проверки

После правки `tokens.json` пересоберите файлы и прогоните проверки

```sh
python3 brand/build.py
python3 brand/check_contrast.py
python3 -m unittest discover -s brand -p 'test_*.py'
```

`python3 brand/build.py --check` ничего не пишет и завершается с ошибкой, если `dist` устарел. Это удобно для CI

Новое сочетание цвета текста и фона в `base.css` добавляйте в `contrast-pairs.json`. Тест сверяет список с правилами `base.css` и падает, если цвет текста не проверяется ни в одной паре или если правило задаёт цвет и фон, а их пары нет в списке. Текст на фоне, унаследованном от родителя, тест не видит: такую пару перечисляйте сами

## Логотип

Логотипы не хранятся в репозитории, причина описана в [ASSETS.md](ASSETS.md). Перед открытием витрины скачайте их командой `python3 brand/fetch_logos.py`

- Используйте только файлы из брендбука, без перерисовки, смены цветов, пропорций и поворота
- На светлом фоне ставьте версию для светлого фона, на тёмном фоне версию для тёмного. Класс `.fsp-only-light` или `.fsp-only-dark` показывает нужную версию под активную тему
- Оставляйте охранное поле. Класс `.fsp-logo` задаёт его от высоты логотипа по сетке построения со страницы брендбука
- Не уменьшайте логотип мельче, чем ФСП ставит его на своём сайте. На узком экране ставьте короткую версию со знаком и надписью "ФСП", как в мобильной шапке сайта ФСП

Численных правил охранного поля и минимального размера брендбук не даёт. Выведенные значения и их обоснование лежат в группе `logo` файла `tokens.json`. Полный набор версий логотипа смотрите на [странице брендбука](https://fsp-russia.ru/press/brandbook/) и на [странице логотипов](https://fsp-russia.ru/press/logotip/)
