# API сервиса matcher

> [!NOTE]
> Файл собран командой `uv run python scripts/gen_docs.py` из каталога `matcher/`. Не правьте его руками: правьте источник и пересоберите файл. Источник — OpenAPI приложения `create_app()` из [`app.py`](../../../matcher/src/matcher/app.py) и роли из `require()` в [`auth.py`](../../../matcher/src/matcher/auth.py)

Подбор кандидатов под потребность работодателя. Спецификация OpenAPI 3.1.0 целиком лежит рядом, в [openapi.json](openapi.json); запущенный сервис отдаёт её по `/openapi.json`, а Swagger UI — по `/docs`

Ключ передаётся заголовком `Authorization: Bearer <ключ>`. Роль `admin` проходит любую проверку роли, поэтому стоит в каждом списке ролей. Формат ошибки — объект `detail` FastAPI: строка или список ошибок проверки схемы

## Ключи

### `POST /keys`

**Выпустить сервисный ключ**

Ключ возвращается один раз; сервис хранит только его хэш

Роль: `admin`

Тело запроса, обязательно:

- `application/json`: [KeyCreate](#keycreate)

Ответы:

| Код | Описание | Тело |
|---|---|---|
| `201` | Успешный ответ | [KeyIssued](#keyissued) |
| `401` | Нет ключа или ключ отозван |  |
| `403` | Ключ не имеет нужной роли |  |
| `422` | Тело или параметры запроса не прошли проверку схемы | [HTTPValidationError](#httpvalidationerror) |

### `GET /runs/{run_id}/results`

**Выдача готового прогона с фильтрами**

Сужает выдачу готового прогона без нового подбора и ничего не пишет. Все фильтры необязательны и действуют вместе

Роль: `admin` или `client`

Параметры:

| Имя | Где | Обязательный | Тип | Описание |
|---|---|---|---|---|
| `run_id` | path | да | string (uuid) |  |
| `city` | query | нет | string или null | Город кандидата, без учёта регистра |
| `relocation` | query | нет | boolean или null | Готовность к переезду |
| `work_format` | query | нет | одно из `"office"`, `"hybrid"`, `"remote"` или null | Предпочтительный формат работы; кандидат без предпочтения проходит |
| `grade_confirmed` | query | нет | boolean или null | Грейд подтверждён тестом |
| `skills` | query | нет | array из string | Коды навыков ref.skills.code; нужны все, уровень не важен |
| `salary_max` | query | нет | integer, ≥ 0 или null | Бюджет: нижняя граница ожиданий кандидата не выше; ожидания в другой валюте или без ожиданий проходят |
| `min_score` | query | нет | number, ≥ 0.0, ≤ 1.0 или null | Нижняя граница final_score |
| `view` | query | нет | одно из `"full"`, `"brief"` | brief — только candidate_id, rank и final_score |

Ответы:

| Код | Описание | Тело |
|---|---|---|
| `200` | Успешный ответ | [ResultsOut](#resultsout) |
| `401` | Нет ключа или ключ отозван |  |
| `403` | Ключ не имеет нужной роли |  |
| `404` | Прогона нет |  |
| `409` | Прогон ещё не завершён |  |
| `422` | Тело или параметры запроса не прошли проверку схемы | [HTTPValidationError](#httpvalidationerror) |
