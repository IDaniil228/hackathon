# Архитектура API

Источники требований — [ТЗ](../ФСП%20спец.%20трек%20ТЗ.pdf), [решения команды](../Идеи.md) и [предметная схема](../Структура%20БД.md). Код моделей и последовательность Alembic определяют фактическую схему, SQL-выгрузка служит материалом для чтения

## Границы

API владеет пользовательскими сценариями и схемами `core`, `ref`, `profile`, `assess`, `hire`. Matcher пишет `match.*`, API только читает эту схему. Taskgen владеет заданиями, ответами и технической оценкой в своей базе

Клиенты сервисов передают только ключи роли `client`, кандидат определяется строкой `profile.candidates.user_id`. API не содержит embedding-настроек и не повторяет алгоритм подбора

HTTP-обработчики находятся в `app/handlers`, общие права — в `security.py`, проекция приватности — в `visibility.py`, применение результата — в `grading.py`, очередь — в `operations.py`. Lifespan закрывает engine, HTTP-клиенты и фоновые задачи

## Надёжность

Сервисная операция фиксируется до внешнего вызова. Фоновый исполнитель использует сохраняемое состояние, PostgreSQL lock защищает единственного исполнителя. Перезапуск помечает прерванный POST как неоднозначный, а оценку сверяет чтением результата

Результат теста применяется под блокировками попытки и кандидата, текущая история грейда и денормализованная категория изменяются одной транзакцией. Уже применённый результат не запускает повторную оценку

Runtime-роль не владеет таблицами, миграции выполняет отдельный процесс. `api/db-init.sql` выдаёт права на чтение `match.*`, без записи или изменения схемы

## Приватность

Все карточки и PDF используют актуальную проекцию. Контакты, ссылки и сведения ФСП имеют независимые условия показа. Исходный документ не становится публичным после принятия приглашения

Исторический свободный текст matcher не выдаётся автоматически: он мог запомнить скрытые данные. API возвращает разрешённые структурированные факторы и текущие карточки без собственного расчёта ranking

Experimental public contacts требуют глобальной настройки и отдельного согласия кандидата. Пользователь согласовал это отступление от ТЗ, но режим по умолчанию сохраняет требуемую механику

## Переписка людей

Переписка находится в `hire.conversations` и `hire.messages`, отдельно от чата уточнения matcher. Диалог привязан к конкретному приглашению и двум участникам. Открытие доступно сразу после отправки предложения с обязательной зарплатой, а ответ не меняет статус приглашения или права на контакты

Первый элемент истории ссылается на приглашение; его текст не копируется в другую таблицу. Обычные сообщения хранят текст и `client_message_id`. Блокировка строки диалога упорядочивает записи, чтобы курсор не пропустил сообщение из поздно завершённой конкурентной транзакции

Отказ, отзыв или истечение предложения блокируют отправку, как и закрытие диалога участником. История остаётся доступна только собеседникам; скрытие профиля в поиске не делает её общедоступной

## ФСП и документы

Демонстрационный реестр использует одноразовый код и синтетические результаты, не имитирует настоящий OIDC. Production-адаптер требует договора о стабильных participant/event/result IDs, доказательстве владения, исправлениях, отзыве результатов и разрешённой обработке данных

PDF использует существующие бренд-токены, SVG и шрифты. Renderer может читать только файлы `brand/`; пользовательский текст экранируется. Разбор загруженного PDF выполняется отдельным ограниченным процессом; перенос предложений требует подтверждения кандидата

## Ограничения текущего среза

- Create/refine восстанавливаются через атомарный `request_ref` в сервисах; смена ключа во время неоднозначной операции требует сверки оператором
- LLM-разбор включается явно, использует общий слой taskgen и проверяльщик фактов; отказ даёт детерминированные предложения. OCR отсутствует
- Capability показывает наличие шаблонов, не все параметры квот taskgen
- Боевое SMTP-подключение зависит от конфигурации, демонстрационный токен подтверждения доступен только владельцу аккаунта
- Общий Compose сохраняет устройство существующего сервера БД и не изолируется одним project name
- GitHub App и подключение дополнительных рекрутеров отсутствуют
