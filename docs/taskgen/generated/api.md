# API сервиса taskgen

> [!NOTE]
> Файл собран командой `uv run python scripts/gen_docs.py` из каталога `taskgen/`. Не правьте его руками: правьте источник и пересоберите файл. Источник — OpenAPI приложения `create_app()` из [`app.py`](../../../taskgen/src/taskgen/app.py) и роли из `require()` в [`auth.py`](../../../taskgen/src/taskgen/auth.py)

Генерация и оценка заданий для теста на грейд. Спецификация OpenAPI 3.1.0 целиком лежит рядом, в [openapi.json](openapi.json); запущенный сервис отдаёт её по `/openapi.json`, а Swagger UI — по `/docs`

Ключ передаётся заголовком `Authorization: Bearer <ключ>`. Роль `admin` проходит любую проверку роли, поэтому стоит в каждом списке ролей. Формат ошибки — объект `detail` FastAPI: строка или объект с полями, которые называет описание ответа

## Шаблоны

### `POST /templates`

**Загрузить шаблон**

Принимает один md-шаблон: телом запроса с Content-Type text/markdown или JSON с полем body. Шаблон ищется по имени из frontmatter. Если тело не изменилось, ничего не пишется; иначе создаётся следующая версия, а прежняя перестаёт быть текущей и остаётся в БД. Шаблон с кодом до записи проверяется в песочнице на нескольких seed: верные решения проходят все кейсы, неверные ловятся; на это уходят секунды, у шаблона на C++ — до десятков секунд. Эмбеддинг описания считается после ответа; его сбой не отменяет загрузку

Роль: `admin`

Тело запроса, обязательно:

- `text/markdown`: string
- `application/json`: [TemplateUpload](#templateupload)

#### TemplateUpload

| Поле | Тип | Обязательное | По умолчанию | Описание |
|---|---|---|---|---|
| `body` | string | да |  | md-шаблон целиком: frontmatter и разделы |
| `source` | string или null | нет |  | Имя файла для сообщений об ошибках |

Ответы:

| Код | Описание | Тело |
|---|---|---|
| `200` | Успешный ответ | [ImportResult](#importresult) |
| `400` | Тело запроса не читается: неверный JSON или не UTF-8 |  |
| `401` | Нет ключа или ключ отозван |  |
| `403` | Ключ не имеет нужной роли |  |
| `415` | Неподдерживаемый Content-Type |  |
| `422` | Шаблон не прошёл проверку. detail.errors перечисляет все проблемы: файл (source), поле frontmatter, раздел тела или seed прогона в песочнице (location) и причину (message) |  |
| `503` | Песочница недоступна: шаблоны с кодом не проверены, ничего не записано |  |

## Тестовые сессии

### `POST /sessions`

**Создать тестовую сессию**

Отбирает шаблоны области по заявленному грейду и навыкам кандидата отдельно для каждого типа заданий и создаёт сессию со всеми заданиями. Первые задания каждого типа, по квоте min_claimed_per_kind, всегда заявленного грейда. Ответ приходит, когда готово первое задание; остальные создаются в фоне и появляются в GET /sessions/{id} по мере готовности, сессия при этом в статусе generating. Задание с кодом выдаётся только после того, как эталон прошёл все его тесты в песочнице. Шаблон, который не дал экземпляра, заменяется другим того же грейда и типа. Параметры отбора берутся из настроек теста; переопределить их может только admin. Если первое задание создать не удалось, сессия остаётся со статусом failed, а detail ответа содержит message и session_id

Роль: `admin` или `client`

Тело запроса, обязательно:

- `application/json`: [SessionCreate](#sessioncreate)

Ответы:

| Код | Описание | Тело |
|---|---|---|
| `201` | Успешный ответ | [SessionOut](#sessionout) |
| `401` | Нет ключа или ключ отозван |  |
| `403` | Ключ не имеет нужной роли или client передал selection_override |  |
| `409` | В области нет шаблонов или шаблонов заявленного грейда какого-то типа меньше квоты min_claimed_per_kind; detail называет тип и число |  |
| `422` | Неизвестная область, грейд или навык; неверные параметры отбора |  |
| `500` | Шаблон первого задания и его замены не дали экземпляра |  |
| `502` | Модель генерации недоступна или не написала условие |  |
| `503` | Песочница не настроена или недоступна; сессия failed |  |

## Оценка

### `POST /tasks/{task_id}/answer`

**Отправить ответ на задание**

Сохраняет ответ кандидата и поведенческие сигналы фронтенда. Код сразу прогоняется на скрытых тестах в песочнице и статическими анализаторами; результат прогона в ответе не раскрывается. На тестовую задачку отвечают полем choice — id варианта, на остальные задания — полем content. Повторная отправка до оценки сессии заменяет ответ

Роль: `admin` или `client`

Параметры:

| Имя | Где | Обязательный | Тип | Описание |
|---|---|---|---|---|
| `task_id` | path | да | string (uuid) |  |

Ответы:

| Код | Описание | Тело |
|---|---|---|
| `200` | Успешный ответ | [AnswerAccepted](#answeraccepted) |
| `401` | Нет ключа или ключ отозван |  |
| `403` | Ключ не имеет нужной роли |  |
| `404` | Задание не найдено |  |
| `409` | Сессия уже оценена или задание ещё не готово |  |
