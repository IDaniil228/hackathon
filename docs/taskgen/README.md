# Документация сервиса taskgen

taskgen — сервис платформы, который генерирует задания теста на грейд ИТ-кандидата, проверяет их до выдачи и оценивает ответы. Код сервиса лежит в [`taskgen/`](../../taskgen), краткое описание и запуск — в его [README](../../taskgen/README.md)

Разделы идут в порядке требований к сопроводительной документации из раздела 3.4 ТЗ. Сборка в один файл берёт разделы в порядке ссылок этого списка

1. [Архитектура](architecture.md) — функции сервиса, модули, жизненный цикл сессии и задания, хранение и место сервиса в платформе
2. [Механика тестирования](testing-mechanics.md) — шаблон и экземпляр, отбор заданий, балл, грейд и обоснование устойчивости к распространению заданий
3. [Валидация](validation.md) — что и как проверяется, результаты шлюза банка шаблонов и процедура на пилотных данных
4. [Развёртывание](deployment.md) — сборка, запуск в Docker и локально, первый ключ, импорт банка
5. [API](generated/api.md) — эндпоинты, роли, тела запросов, ответы и коды ошибок; спецификация — [openapi.json](generated/openapi.json)
6. [Настройки](generated/settings.md) — все настройки сервиса с переменными окружения и значениями по умолчанию
7. [Библиотеки и компоненты](generated/libraries.md) — версии зависимостей, окружения песочницы и образы контейнеров
8. [Банк шаблонов](generated/templates.md) — шаблоны заданий и демонстрационные вакансии

Файлы в [`generated/`](generated) собирает из кода `uv run python scripts/gen_docs.py` в каталоге `taskgen/`; тест `tests/test_docs_generated.py` падает, если они отстали от кода

## Сборка в один файл

ТЗ требует сопроводительную документацию в формате doc или pdf. Файл `docs/taskgen/taskgen.docx` собирается из разделов выше и в репозиторий не коммитится:

```sh
cd taskgen
nix shell nixpkgs#pandoc nixpkgs#mermaid-cli -c uv run python scripts/gen_docs.py bundle
```

Без Nix подойдут `pandoc` и `mmdc` из [mermaid-cli](https://github.com/mermaid-js/mermaid-cli), установленные любым способом. Без `mmdc` диаграммы попадают в файл исходным текстом mermaid. Флаг `--output taskgen.pdf` собирает PDF, если у pandoc есть PDF-движок, например LaTeX с кириллицей
